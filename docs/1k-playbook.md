# The 1K+ playbook (from 30 reels on @unexplored.truths, 15 Nov 2026)

## What the data says
| Avg watch time | Result |
|---|---|
| under 8 s | stuck at ~150-700 views (Ittikkora x2, Pathinettam Koottam, Beypore station, Muziris, a village...) |
| 9-13 s | 1,100-1,700 views, almost every time |
| 15 s + | 2,000+ |
| 18 s + with a local tag | 62K-68K (Kothayi, Ezhimala) |

Watch time in the first seconds decides everything. Avg watch < 8 s = the hook lost people.
Dharmadam (13 s, 216 views) shows the other killer: a pretty place with no mystery gets no shares.

## Hook (0-2 s) - must pass all 5
1. **Frame 1 is the strongest image** + the on-screen question. No fade-in, no map, no title card, no dark empty frame.
2. **First spoken line ≤ 2.5 s** and contains a **name Malayalis know** (a town, temple, person) + **a contradiction or stakes**.
3. **Opens a loop** - a question answered only near the end ("വാങ്ങിയത് ആര്?", "എന്തുകൊണ്ട്?").
4. **No intro words** ("ഇന്ന് നമ്മൾ...", "ഇതാണ്..."). Start mid-story.
5. **Local hook for sharing**: name the district early (കണ്ണൂർ, പയ്യന്നൂർ...).

Hook templates that worked:
- Surprising link: "കളരിപ്പയറ്റ് ചൈനയിലെത്തിച്ചത് ഒരു മലയാളി?" (Kalari, 2,242)
- Forbidden/secret: "ഇവിടെ ഫോട്ടോ എടുക്കാൻ പാടില്ല" (1,316)
- Local villain/legend: "കള്ള കോതായി" (Kothayi, 62K)
- Twist of a known place: "ഡച്ചുകാർ കണ്ണൂർ കോട്ട വിറ്റു! വാങ്ങിയത് ആര്?"
Avoid: obscure names first (Ittikkora, Pathinettam Koottam), "beautiful place" topics, faraway history (Rome, Muziris) without a Kerala twist up front, repeating a topic already posted.

## Flow (35-45 s, ~450-500 Malayalam characters of voice in total)
| Time | Beat |
|---|---|
| 0-3 s | Hook: name + twist + open question |
| 3-8 s | Stakes: why this matters / what was at risk |
| 8-30 s | 3 reveals, a new fact or turn every 5-7 s ("പക്ഷേ...", "പിന്നെയാണ് ട്വിസ്റ്റ്") |
| 30-38 s | Payoff: answer the hook question (the most beautiful shot) |
| 38-42 s | One ask: comment question + tag a friend from that place |

## Editing (automatic in the pipeline unless noted)
- cine pass: punch-in at every cut (pattern interrupt), slow push/pan, one overlay across scenes, vignette.
- TARGET_SECONDS = 40; the voice is sped up (max 1.15x) when a script runs long - but write short.
- In scene code (manual): key element visible at t=0 of every scene; something moves every second;
  parallax layers; the payoff shot is the prettiest.
- Cover: the twist line, 4-6 words, the accent on the question word.

## Before posting - checklist
- [ ] Topic not posted before (check logs/stats.json titles)
- [ ] Hook passes all 5
- [ ] Total voice ≤ 500 characters (≈ 42 s)
- [ ] Frame 1 of the hook is strong (look at the cover AND frame 0)
- [ ] One reel a day; never archive a reel in its first 7 days
